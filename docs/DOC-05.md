# Tarifas ficticias para la prueba
El plan ZT-START-1 aplica un cargo de servicio de 6,0% del precio base de cada entrada, más $120 ARS por entrada vendida. El plan ZT-PRO-2 aplica 4,5% más $90 ARS por entrada. El cargo se calcula por entrada pagada y no sobre reservas de carrito.

# Ejemplo
Para una entrada base de $10.000 ARS en ZT-PRO-2, el cargo es $450 + $90 = $540 ARS. Este importe no incluye impuestos adicionales que un proveedor de pagos pudiera aplicar.

# Vigencia y prioridad
Estas tarifas aplican exclusivamente del 01/09/2026 al 31/03/2027. El documento DOC-12 contiene un tarifario histórico que no debe aplicarse a ventas posteriores a agosto de 2026.

# Precisión
Las comisiones de servicio no son lo mismo que el monto neto liquidado al organizador.
