# Alcance del servicio
ZocoTickets es una plataforma ficticia de publicación y venta de entradas para eventos. Este documento es parte de un escenario sintético de evaluación; sus números, políticas y planes no describen las condiciones comerciales reales de Zoco.

# Roles
Los organizadores crean eventos y consultan ventas. Los asistentes compran y presentan entradas. Los operadores atienden reclamos. Los validadores controlan el acceso por código QR. El equipo de soporte puede escalar incidencias, pero no modificar importes de liquidación sin autorización.

# Canales
El panel web de organizadores se utiliza para publicar eventos. La aplicación de escaneo se utiliza en la puerta. El canal de soporte ficticio registra tickets mediante un número único.

# Distinción de productos
ZocoTickets gestiona entradas y eventos; el producto simulado ZocoPagos procesa los pagos, pero esta prueba no presupone integración productiva entre ambos. Ningún participante necesita acceder a servicios reales.
