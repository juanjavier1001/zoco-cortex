# Lotes
Cada lote tiene precio, cupo y ventana de venta. Si el cupo global del evento se agota, los lotes restantes dejan de ofrecer entradas. Una reserva de carrito no equivale a pago aprobado.

# Reserva temporal
La reserva del carrito dura 12 minutos desde su creación. Vencido el plazo se libera el cupo si el pago no fue confirmado.

# Diferencias
Una entrada EMITIDA tiene identificador único y QR. Una entrada RESERVADA todavía no habilita el ingreso. Una entrada ANULADA no puede validarse en puerta.

# Casos frecuentes
Si el cobro se aprobó pero la entrada no aparece, el asistente debe recomendar verificar el correo y luego abrir un reclamo de emisión. No debe crear entradas manualmente.
