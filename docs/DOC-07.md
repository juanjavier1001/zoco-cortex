# Planes ficticios
ZT-START-1: sin mínimo mensual de entradas; incluye dos usuarios organizadores y reportes básicos.
ZT-PRO-2: requiere al menos 400 entradas pagadas por mes calendario; incluye diez usuarios organizadores y exportación de reportes.
ZT-ENTERPRISE-3: mínimo de 3.000 entradas pagadas por mes; condiciones adicionales sujetas a acuerdo escrito.

# Cálculo del mínimo
Para el mínimo mensual cuentan entradas pagadas y no reembolsadas. Las reservas temporales y entradas gratuitas no cuentan. El umbral se mide por organizador, no por evento aislado.

# Diferencia con tarifas
El porcentaje del cargo de servicio se encuentra en DOC-05. Este documento define requisitos de plan y no porcentajes.

# Vigencia
Estos requisitos aplican del 01/09/2026 al 31/03/2027. Para períodos anteriores consultar DOC-12.
