# Registro
Para solicitar el alta, el organizador informa razón social o nombre, correo de contacto, CUIT ficticio para la prueba y datos del responsable. La verificación manual tarda hasta dos días hábiles desde que la solicitud está completa.

# Estados
BORRADOR: el solicitante aún puede corregir datos. EN_REVISION: el equipo verifica documentación. APROBADO: puede publicar eventos. RECHAZADO: se informa el motivo y puede presentar una nueva solicitud.

# Documentación
Para el escenario de prueba se aceptan archivos simulados; está prohibido solicitar DNI, CUIT, claves o comprobantes reales a los postulantes.

# Acciones restringidas
El asistente puede explicar requisitos, pero no prometer que una cuenta fue aprobada, ni cambiar el estado sin consultar al sistema correspondiente.
