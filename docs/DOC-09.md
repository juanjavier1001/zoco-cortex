# Transferencias
La transferencia entre asistentes se permite solo para eventos que tengan la opción habilitada por el organizador. Una entrada puede transferirse una vez; la transferencia invalida el QR anterior y emite uno nuevo para el receptor.

# Bloqueos
No se puede transferir una entrada ANULADA, REEMBOLSADA ni una que ya haya sido validada en puerta. El sistema registra fecha, identificador de entrada y nuevo titular.

# Seguridad
El agente puede informar el proceso, pero no pedir contraseña ni código de acceso al asistente. No puede crear ni forzar una transferencia sin una operación autenticada.

# Ejemplo
Si María transfiere a Pedro una entrada EMITIDA, el QR previo de María deja de funcionar aunque alguien conserve una captura.
